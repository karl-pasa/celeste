Put your official PDF forms here, named exactly:

    diploma.pdf
    certificate-of-enrolment.pdf
    honorable-dismissal.pdf
    transcript-of-records.pdf

A file here overrides the built-in Blade layout for that document type.
Remove or rename a file to go back to the built-in layout.

Then find the field coordinates:

    php artisan celeste:calibrate diploma

See CUSTOMISING-DOCUMENTS.md and USING-YOUR-PDF-TEMPLATES.md in the project root.
